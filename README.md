💊 Sotota Pharmacy - Smart Management System
🚀 Overview
Sotota Pharmacy Management System is a responsive web application designed to simplify pharmacy and retail shop operations. Built using PHP, MySQL, HTML5, CSS3, and JavaScript, this system provides an efficient platform for inventory tracking, real-time invoice creation, customer management, and sales recording.

✨ Key Features
🔒 Secure Admin Authentication: Safe login and logout functionality with PHP session management (index.php, logout.php).

📊 Analytics Dashboard: Displays total products, total revenue, low-stock alerts, and recent sales records at a glance (dashboard.php).

📦 Complete Inventory Control: Add new medicines with expiry dates, update stock quantities, delete items, and automatically trigger low-stock status when inventory falls below 10 units (inventory.php).

🧾 Dynamic Billing & Invoice Generator: Generates unique invoice numbers (INV-XXXX), performs automatic total calculations, validates available stock in real-time, and displays a live invoice preview (billing.php).

👤 Customer Management: Stores customer details and includes a live search bar for quick client lookups (customers.php).

📜 Sales History & Reports: Retains complete transaction records and features a built-in print option for generating physical sales reports (history.php).

🛠️ Tech Stack
Frontend: HTML5, CSS3 (Google Fonts Poppins), JavaScript

Backend: PHP (Procedural)

Database: MySQL (mysqli extension)
